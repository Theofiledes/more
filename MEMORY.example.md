prompt, so anything here shapes how BMO talks to you.

that runs during lulls and whenever you tell BMO goodnight. You can also edit this file
by hand, or through the in-app workspace editor.

This file is your copy: `MEMORY.md` is gitignored and created from this template on
first run, so what BMO learns about you never lands in the repo.
